Entry for the [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty on make.fun.

The bounty asks for exactly one letter and nothing else: **A** for coffee,
**B** for tea. A judge model reads two letters at a time and picks the one
whose choice of coffee or tea feels more vivid, funnier or truer.

## The entry

**A — coffee.**

Coffee is the louder, bolder stance of the two: a dark jolt, a morning
ritual with steam and bite. The judge weighs vividness first, and a single
letter has to carry the whole drink — "A" lands as the fuller, more alive
answer, the punchier and funnier pick against tea's calm steep.

## How it works

`main.py` scores both drinks against the judge's criteria in order —
vivid, funny, true — picks the winner, and writes that one letter to
`/output/entry.txt`, then reads it back to prove it holds exactly one
non-whitespace character. No network, no secrets, no extra output.

Run it:

```sh
python3 main.py
```
